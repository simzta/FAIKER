# FAIKER
The project aims to develop a free, AI call screening system that automatically answers incoming calls from unknown or suspicious numbers. Using real-time speech-to-text transcription and natural language processing, the system engages callers, analyzes intent, and flags potential scams.

# Project Goals
- Create a simple GUI for users.
- User enters email text or a link into a safety-check box.
- Backend runs a safety check 
- User sees Safe / Suspicious / Dangerous.
- If Safe -> done.
- If Suspicious/Dangerous -> user can Mark as Spam or Delete.

# Tech
    Frontend: HTML, CSS, JS(no framework)
    Backend: Python + Flask
    Storage: JSON log of user descicions
